# Contributing

Thanks for helping improve SM64 Diorama MR.

## Before opening a pull request

- Base changes on `main` and keep them focused.
- Describe the Quest model, Horizon OS version, and test scenario.
- Do not commit generated APKs, executables, build folders, ROMs, extracted
  Nintendo assets, saves, logs, signing files, credentials, or personal paths.
- Do not introduce third-party content unless you have the right to contribute
  it and its applicable notice is preserved.
- Preserve existing upstream attribution and component license notices.
- Run the relevant Android/native build checks when available and document any
  hardware testing performed.
