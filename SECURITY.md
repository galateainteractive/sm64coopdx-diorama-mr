# Security policy

## Supported version

Security fixes are made against the current `main` branch and the most recent
public beta. Older builds may not receive separate updates.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** flow under the repository's
Security tab. Please include the affected version, platform, reproduction
steps, and impact. Do not publish an exploit or sensitive material in a public
issue before a fix is available.

Never attach or paste:

- a Super Mario 64 ROM or extracted Nintendo assets;
- release keystores, signing-property files, passwords, tokens, or API keys;
- Quest serial numbers or account identifiers;
- logs that still contain personal Windows paths or unrelated private data.

For ordinary gameplay bugs, use the public bug-report template after reviewing
logs and screenshots for private information.
